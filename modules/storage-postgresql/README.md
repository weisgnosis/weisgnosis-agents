# Optional PostgreSQL storage

This fourth library artifact provides an explicit PostgreSQL backend for the harness VersionedJsonStore prerequisite. It depends on harness; core/harness/MCP do not acquire a PostgreSQL dependency. The host supplies javax.sql.DataSource and owns its pool, JDBC driver and connection/login/socket deadlines. PostgreSQL JDBC 42.7.11 is Test-only here.

The [backend contract](src/main/scala/com/weisgnosis/agents/storage/postgresql/README.md) records exact address/revision, Unicode, schema ownership, cancellation and reviewed source identities. The [real PostgreSQL fixture](src/test/scala/com/weisgnosis/agents/storage/postgresql/README.md) covers publication and composed memory/transcript/checkpoint behavior; default provider-free verification does not require a public model endpoint.

The [versioned publication port](../harness/src/main/scala/com/weisgnosis/agents/harness/storage/README.md#versioned-json-publication) and optional PostgreSQL backend support explicit host-selected addresses. [Memory](../harness/src/main/scala/com/weisgnosis/agents/harness/memory/README.md#versioned-remote-memory) and [transcript](../harness/src/main/scala/com/weisgnosis/agents/harness/transcript/README.md#versioned-remote-transcript) adapters use bounded whole aggregates and retry only definite CAS conflicts. [Acting checkpoints](../harness/src/main/scala/com/weisgnosis/agents/harness/storage/README.md#versioned-acting-checkpoints) validate suspended data before one host-expected CAS without read-before-write or retry; source/full/artifact checks pass and final documentation approval passed. Hosts retain DataSource/schema ownership, runtime restoration gates, authentication, exclusive execution and replay/idempotency. Remote segmentation/discovery/pruning/layout migration and remaining provider/platform/release gates stay open. Package contracts and the tracker own exact review/verification evidence.

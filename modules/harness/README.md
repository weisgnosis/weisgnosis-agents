# weisgnosis-agents-harness

Standalone context and permission components built on core.

| Package | Current status |
| --- | --- |
| [memory](src/main/scala/com/weisgnosis/agents/harness/memory/README.md) | Pair-safe compaction, summary/user provenance, token estimation and daily extraction/local storage and atomic in-memory and recoverable local consolidation |
| [transcript](src/main/scala/com/weisgnosis/agents/harness/transcript/README.md) | Typed observation projection, atomic in-memory linkage, and strict scoped local persistence; remote segments pending |
| [storage](src/main/scala/com/weisgnosis/agents/harness/storage/README.md) | Internal cooperative scoped ownership shared by memory and transcripts |
| [eviction](src/main/scala/com/weisgnosis/agents/harness/eviction/README.md) | Above-80k eviction, 2k head/tail previews, explicit-trust local store |
| [permission](src/main/scala/com/weisgnosis/agents/harness/permission/README.md) | Immutable decisions, Promise coordination, serializable durable approval values |
| [subagent](src/main/scala/com/weisgnosis/agents/harness/subagent/README.md) | Planned supervision and task promotion |
| [plan](src/main/scala/com/weisgnosis/agents/harness/plan/README.md) | Planned mutation restrictions and shell inspection |

MemoryFlushManager supplies daily extraction through an injected DailyMemoryStore and can be installed as the compactor flush callback. LocalDailyMemoryStore supplies a scoped backend for host-controlled workspaces with exclusive cooperative ownership and atomic daily replacement. MemoryConsolidator enforces its counter budget before an atomic content/progress commit; MemoryRepository.inMemory implements shared daily/consolidation authority. LocalMemoryRepository supplies the daily/consolidation ports with shared ownership and journal recovery before each operation. Transcript recording can be installed through TurnCompletionObserver with an explicit anonymous-message policy. Completion-triggered flush scheduling is available through MemoryFlushScheduler. MemoryConsolidationScheduler adds opt-in owner-coalesced background consolidation with explicit result reporting. Explicit acknowledged-daily archival is available through MemoryRepository.retention. Remote memory/transcript storage, automatic session pruning, general middleware, and durable workflow storage remain pending. Hosts choose a memory store and supply summarization/offload effects and authenticated approval routing.

Local storage requires WorkspaceTrust.HostControlled and protected filesystem ancestors. Tool-result publication requires hard-link support; memory/transcript publication requires atomic-move support. It is not a sandbox for untrusted workspaces. See [implementation notes](../../docs/architecture/phase-4-implementation.md) and the [tracker](../../docs/architecture/tracker.md).

## Daily retention capability

MemoryRepository.retention explicitly archives only acknowledged exact daily versions older than a supplied cutoff. Its in-memory transition is atomic; the local protocol verifies archive copies before checkpoint advancement and active-file removal. Multiple versions coexist and failures can leave conservative pending state. This is opt-in storage authority, not an installed maintenance policy or session-deletion mechanism. See the [memory contract](src/main/scala/com/weisgnosis/agents/harness/memory/README.md) for recovery limits and source identities.

## Combined maintenance scheduling

MemoryMaintenance runs a repository-bound consolidator followed by acknowledged-daily archival under an explicit calendar policy and zone. MemoryMaintenanceScheduler owns one Maintenance admission/job and reports the aggregate after work. The consolidation-only adapter keeps its prior behavior; choose the combined adapter for retention instead of installing both against one throttle window. ## Explicit transcript pruning

LocalTranscriptRetention prunes one explicitly selected inactive transcript under the same scoped ownership lease as its writer. Strict decoding and the maximum of file modification time/all recording times protect corrupt or recent data. Deletion retires persisted identity and touches only transcript.jsonl. Active/stale ownership fails safely; explicit expiry policy is available below, while automatic session discovery remains pending; explicit batch maintenance is implemented below. See the [transcript contract](src/main/scala/com/weisgnosis/agents/harness/transcript/README.md).

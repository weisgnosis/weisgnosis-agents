# weisgnosis-agents-mcp

Typed captured-session expiry and explicit host recovery through existing joined manager removal/fresh registration are independently reviewed and verified. Automatic replay is intentionally excluded; durable host recovery remains unfinished.

This module supplies checked MCP messages, selected 2025-06-18 payload helpers, bounded scoped request correlation and accepted connection ownership over an injected port. A direct-process stdio adapter, initialized client, bounded optional outbound cancellation, bounded discovery, manual Toolkit binding and bounded scoped manager are independently reviewed and verified. Bounded HTTP JSON/SSE framing, response-local SSE event-ID snapshots and the scoped HTTP adapter with explicit GET, bounded same-send continuation, bounded listener resumption and explicit session termination are also reviewed; opt-in exact-class raw-SSE-body-I/O recovery is accepted; host-owned replacement after typed expiry is supported; real expiry/truncation interoperability remains unverified.

The protocol boundary rejects ambiguous variants, duplicate keys and malformed known fields. Numeric envelope identities use a signed 256-bit parser-compatible range. Payload extensions remain data; tool annotations confer no execution authority. Schemas, URI/base64 strings and timestamps are retained without evaluation or resource fetching.

The request registry allocates monotonic numeric IDs before sending, atomically settles replies and retains complete terminal causes. Each request requires its own short-lived scope. The connection composes that registry with bounded operations, a reader and a separate bounded server-response writer. Its transport belongs to the host and must outlive connection cleanup. Optional cancellation notifications use that writer, drop on a full queue and have no delivery acknowledgement. HTTP eligibility begins after validated response headers; legacy ports and stdio signal after successful send. Pre-header HTTP cancellation is deliberately ineligible.

Stdio starts host-selected argv without an implicit shell and redirects stderr to discard or inherit. One incoming consumer and serialized frame writes preserve framing; interrupted admitted writes terminate the transport, while cancellation waiting for write admission is harmless. Cleanup shares one outcome and terminates/reaps the direct child before closing streams. Environment and working directory are inherited without configuration overrides. Process-tree containment, graceful shutdown deadlines and reconnects are not implemented.

[McpClient.open](src/main/scala/com/weisgnosis/agents/mcp/client/McpClient.scala) sends initialize, validates the exact 2025-06-18 result, and sends notifications/initialized before publishing the client. The advertised tools capability is required for listToolsPage and callTool. A positive finite configured deadline (default 30 seconds) covers the complete initialization exchange and each list/call operation. Expiry or caller cancellation interrupts and joins owned cleanup; return can exceed the deadline while cleanup completes. Failed initialization closes the connection immediately. Remote protocol rejections retain code, message and explicit data presence in McpRemoteError; tool isError remains a valid call result. The client neither installs server instructions nor grants authority from annotations.

Explicit `discoverTools(maxPages, maxTools, meta)` traverses pages sequentially within positive limits, preserves ordered duplicates, detects cursor cycles and returns no partial catalogue on failure. Each page retains its joined deadline; page metadata is omitted, and the result is not an atomic server snapshot.

[McpTool.bind](src/main/scala/com/weisgnosis/agents/mcp/tool/McpTool.scala) borrows one initialized client and fixes its remote name. The host supplies ToolDef naming/schema/read-only/concurrency declarations and explicitly selects, omits or overrides any descriptive output schema. Checked fixed bindings attach a core policy enforced before raw dispatch and authorization; accepted fixed values survive any later default merge. This is separate from model-overridable defaults and trusted typed execution bypasses the raw policy. Checked bindings can project preset names out of root properties/required and apply model-overridable defaults after authorization; this is not schema evaluation or permission enforcement. All five content variants and nested metadata are preserved; tool isError retains its payload, while Toolkit normalizes RPC failures to textual Error observations without code/data. This neither fetches resources nor grants authority from annotations. Fixed Omit/Propagate metadata policy and the client live restriction control explicit effectful host projection. Resolvers see correlation identity only; model arguments cannot grant propagation. Each invocation snapshots the restriction before resolving, and explicit client metadata remains unaffected. See the [metadata contract](src/main/scala/com/weisgnosis/agents/mcp/tool/README.md#explicit-request-metadata).

The HTTP adapter borrows a host client, owns each response scope, handles JSON/SSE POST replies and session headers, and reserves independent request/control admission. Explicit host-run GET receives server traffic after acknowledged initialization; opt-in bounded resumption retains one listener and captured session across joined GET attempts with a committed cursor. EOF without cursor/budget and 405 leave POST usable. Opt-in continuation resumes the original request after clean SSE EOF or narrowly classified typed connection loss, with joined cleanup and one GET budget. It never replays POST; generic I/O, protocol, mixed-cause and cleanup failures remain terminal. Explicit `terminateSession` performs at most one scoped DELETE with a shared outcome; owner cleanup does not send it. Session expiry terminates the old transport without replay. The [transport contract](src/main/scala/com/weisgnosis/agents/mcp/transport/README.md#http-contract) defines exact limits, required host client behavior and excluded features. The narrowed `open` return type exposes `listen` and `terminateSession` while remaining usable as `McpTransport`; existing client and stdio signatures are unchanged.

# Module index

The four library modules produce separately consumable binary/source JARs and POMs through `sbt packageArtifacts`; [build acceptance](../project/README.md#local-artifact-packaging) records coordinates, dependency scopes and local consumer evidence. Package READMEs describe available source or explicitly label planned designs. Consult the [tracker](../docs/architecture/tracker.md) and [parity audit](../docs/architecture/test-parity.md) for reviewed scope and remaining integration.

| Module | Current status |
| --- | --- |
| [core](core/README.md) | Immutable models, typed events/tools and completed observation payloads, canonical path checks, advisory command screening, scoped model clients, streaming and ReAct execution |
| [harness](harness/README.md) | Memory/transcript storage and maintenance, compaction/eviction, interactive permissions, reviewed plan sessions and controls, scoped task/resource ownership, configured child factories, bounded execution registries, host-held reusable sessions, bounded host session membership and opt-in spawn/send/task/cancel tools |
| [mcp](mcp/README.md) | Checked payloads, bounded correlation, scoped RPC ownership and direct-process stdio with bounded framing; initialized 2025-06-18 capability-checked list/call, joined deadlines and bounded optional outbound cancellation are reviewed; manual Toolkit binding preserves host authority and typed results; bounded scoped management and HTTP transport with explicit GET, bounded same-send continuation, bounded listener resumption and explicit session termination are reviewed; broader transport recovery and manager policies remain pending |

The additional nonpublished [examples](examples/README.md) project compiles and tests host composition across all three libraries. It includes an explicitly enabled live smoke program; ordinary verification stays offline.

Core local tools can stream provisional payload events while preserving one authoritative final result after EOF and cleanup; provider request projection remains separate.

Harness adapters require explicit host installation and ownership. Child factories retain final static tool filtering and injected authorization. Runtime-owned lineage enforces depth through three; reusable sessions retain one child runtime and serialize turns. Model tools bind to a host-selected registry, session or session directory; checked host execution policy selects default promotion or bounded synchronous waiting with joined timeout cancellation. `SubagentConstruction` supplies an opt-in factory path carrying static boundaries and live ancestor Deny/Plan checks into nested children while preserving their confirmation authority. Scoped child forwarding uses runtime execution IDs and the current invocation lease. Bounded inline parsing and read-only local declaration loading are available through the [subagent contract](harness/src/main/scala/com/weisgnosis/agents/harness/subagent/README.md#local-declaration-loading). A finite host-installed [session catalog](harness/src/main/scala/com/weisgnosis/agents/harness/subagent/README.md#named-session-catalog) retains one runtime/history per name; its opt-in named send/task/cancel adapter preserves that fixed authority. Post-promotion/remote event delivery remains unfinished; durable recovery is a separate host contract.

Plan mode provides conservative inspection, live admission, exact-draft host review, request-only context and cooperative local draft storage. Stored drafts reopen unapproved. Strict enter/write/exit tools preserve review authority; configured/observed location metadata grants no filesystem or approval authority. Typed PlanDirectory selects an existing strict descendant of a host-controlled workspace without creating directories or discovering a workspace. A host-installed inherited gate restricts execution if either parent or child is in Plan; inline declarations compose through this construction path; opt-in child-local Plan controls/context are installed through explicit host dependencies. All fourteen inventory methods have bounded adaptations, without Java API/framework parity.

Every change must update affected package documentation, source/test links and scenario mappings. Current reviewer identities, accepted revisions and verification evidence belong in the linked module/package contracts and tracker, not a milestone journal here.

The additive [versioned transcript adapter](harness/src/main/scala/com/weisgnosis/agents/harness/transcript/README.md#versioned-remote-transcript) has final independent source approval, full verification and fresh artifact consumption; final documentation approval passed. It binds append/read to one host-sized aggregate, preserving candidate identities/time across definite CAS retries and validating the complete parent chain. Remote checkpoint persistence, transcript segmentation/discovery/pruning and authenticated execution claims remain unfinished.

Harness adapters require explicit host installation and ownership. Child factories retain final static tool filtering and injected authorization. Runtime-owned lineage enforces depth through three; reusable sessions retain one child runtime and serialize turns. Model tools bind to a host-selected registry, session or session directory. `SubagentConstruction` supplies an opt-in factory path carrying static boundaries and live ancestor Deny/Plan checks into nested children while preserving their confirmation authority. Scoped child forwarding uses runtime execution IDs and the current invocation lease. Bounded inline parsing and read-only local declaration loading are available through the [subagent contract](harness/src/main/scala/com/weisgnosis/agents/harness/subagent/README.md#local-declaration-loading). A finite host-installed [session catalog](harness/src/main/scala/com/weisgnosis/agents/harness/subagent/README.md#named-session-catalog) retains one runtime/history per name; its opt-in named send/task/cancel adapter preserves that fixed authority. Post-promotion/remote event delivery remains unfinished; durable recovery is a separate host contract.

Plan mode provides conservative inspection, live admission, exact-draft host review, request-only context and cooperative local draft storage. Stored drafts reopen unapproved. Strict enter/write/exit tools preserve review authority; configured/observed location metadata grants no filesystem or approval authority. Typed PlanDirectory selects an existing strict descendant of a host-controlled workspace without creating directories or discovering a workspace. A host-installed inherited gate restricts execution if either parent or child is in Plan; inline declarations compose through this construction path; full Plan installation and remaining mappings stay pending.

Every change must update affected package documentation, source/test links and scenario mappings. Current reviewer identities, accepted revisions and verification evidence belong in the linked module/package contracts and tracker, not a milestone journal here.

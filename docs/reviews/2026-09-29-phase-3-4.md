# Independent Phase 3 and Phase 4 review

Date: 2026-09-29. This review follows the original Phase 3 and standalone Phase 4 delivery. The original delivery did not receive independent subagent review; the review below was performed after the user requested it.

## Review assignments

Three subagents reviewed separate concerns: core Pure FP/lifecycle/path safety, harness compaction/storage/permissions, and documentation/English/parity claims. Core and harness reviewers then cross-reviewed each other's fixes. The documentation reviewer also checked the final documentation changes. Review is source-based and supplements execution of the test suite; it does not prove semantic purity or exhaustive upstream parity.

## Findings and resolutions

| Finding | Resolution and evidence |
| --- | --- |
| Path normalization could erase a parent traversal boundary before canonical checks | Reject parent segments before normalization; deterministic path regressions |
| Model resources and readers could survive until the caller's outer scope ended | Give every model request its own scope and every run its own event-hub scope; lifecycle tests cover normal completion, next requests, timeout and cancellation |
| An old interruption recovery could suppress a later run's recovery | Track the current run's history boundary; regressions cover new input and empty-input continuation |
| Concurrent local-store writers could observe incomplete content | Write a scoped temporary file, then publish complete content with an atomic hard link; separate-store concurrency and collision tests |
| Canonical checks were overstated as protection from hostile concurrent filesystem changes | Require explicit WorkspaceTrust.HostControlled and reject Untrusted; document OS-protected ancestors and filesystem requirements |
| Temporary cleanup failure could become an uncaught defect | Report cleanup failure through ZIO logging while preserving the persistence result; deterministic cleanup-failure regression |
| Summary/user coalescing could lose original user content during a later flush | Serialize retained-user provenance and validate it before expansion; repeated-compaction regressions |
| Histories below the trigger were still pruned | Preserve below-trigger input unchanged; boundary regression |
| README and design examples described nonexistent or obsolete APIs | Rewrite current architecture and package indexes; explicitly mark future package designs and historical research |
| Documentation claimed complete parity without method-level evidence | Publish a coverage/gap audit and remove unsupported 1:1 completion labels |
| Best practices were not consistently connected to review and CI | Update AGENTS.md and CONTRIBUTING.md, add a PR checklist, an sbt verify alias, and explicit sbt setup in CI |

## Validation

Formatting and `sbt verify` passed on Microsoft OpenJDK 21.0.11 with Scala 3.9.0: 108 core tests and 40 harness tests, 148 total, with zero failed or ignored tests and zero compiler warnings. The cleanup-failure regression intentionally emits a runtime warning to verify best-effort finalization. Cross-review confirmed both final follow-up fixes; the documentation reviewer found no blocking discrepancy, and the three minor wording corrections were applied. Tests use deterministic scripted model clients and local temporary resources, not live provider endpoints. The English audit scans tracked and newly added Scala, Markdown, and build files for non-English script ranges and reviews changed prose. The scan is supplemental evidence, not automatic natural-language classification. The script scan found no Cyrillic, CJK, Hiragana, or Katakana text in the inspected files. Changed prose and comments are English. Local Markdown link validation passed. Commit-subject screening found no non-English scripts. These checks do not certify all historical commit contents.

## Remaining boundaries

Exhaustive upstream parity remains pending, with gaps in [the parity audit](../architecture/test-parity.md). Live HTTP transport, agent-level harness middleware, durable storage, memory services, subagent supervision, plan mode and MCP remain outside this implementation. Portable result storage requires trusted filesystem ancestors and hard-link support; hostile-workspace sandboxing and crash durability are not provided. Privileged symlink creation was unavailable on the verification host. CI has been configured but its remote execution is not claimed by local verification.

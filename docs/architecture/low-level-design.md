# Low-level contracts

The [before-acting contract](../../modules/core/src/main/scala/com/weisgnosis/agents/core/agent/README.md#before-acting-suspension-and-restoration) stores one AgentResult plus data-only PendingActing. Direct and lazily consumed streaming resume share validation, checkpoint claim, scoped execution and completion observation. Resume claims the saved batch before execution, retains occurrence/context identity and checks the receiving host iteration budget before further reasoning. Checked supplied Success/Error observations are persisted and ledger-marked by original ordinal before interruptible processing, so cancellation preserves completed occurrences and only unfinished local calls execute. Restore rebuilds executable bindings from the host; serialized ToolDefs do not grant execution authority.

Current source declarations are authoritative. This document records API contracts rather than maintaining a second implementation.

## MCP protocol and client boundaries

[McpHttpFraming](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/transport/McpHttpFraming.scala) supplies checked compact JSON encoding and bounded JSON/SSE body pipelines. JSON requires one complete envelope at EOF. SSE handles all newline forms, strips one initial BOM, dispatches on blank lines and discards unfinished events after strict UTF-8 validation. Total wire bytes and event line-content bytes have separate limits; exact accounting and independent review evidence belong to the [framing contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/transport/README.md#http-body-framing). No HTTP request/session API is implemented by this prerequisite.

[McpStreamableHttpTransport](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/transport/McpStreamableHttpTransport.scala) borrows a zio-http Client and scopes each POST or explicitly requested GET response. It supports JSON replies, SSE server messages before the matching reply, session headers, separate bounded request/control admission and terminal ingress overflow. Incoming ownership and terminal publication are interruption-safe. A captured-session 404 ends the old transport without replay through token-free McpSessionExpired; its bounded integration is independently reviewed and verified. The host may join manager removal and acquire/register a fresh initialized client, with new discovery/selection and no retargeting of old snapshots; this is not atomic replacement. Host-run `listen` requires acknowledged initialization. Optional `listen(Resume(maxRestarts))` keeps one listener lease and captured session across bounded cursor-based GET attempts, joining each response cleanup. Listener streams always reject RPC responses. EOF without a cursor/budget and 405 leave POST usable; classified losses without retry authority preserve their Cause. The host owns the listening fiber within the transport lifetime. Optional continuation after clean EOF or narrowly classified typed connection loss retains the original send, ID, permit and captured session, with one bounded GET budget after joined successful cleanup. It never replays POST; unclassified I/O outside the explicit body policy, protocol, mixed-cause and cleanup failures do not retry. Explicit termination snapshots the known session, stops local admission and shares one DELETE outcome after cleanup; owner release never sends DELETE. The [HTTP contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/transport/README.md#http-contract) defines exact media types, byte limits, cleanup, host client restrictions and excluded transport features. Opt-in body-I/O policies add only exact-class, cause-free IOException from raw SSE bodies before framing; acquisition, JSON/acknowledgement, protocol and cleanup failures remain outside this additional recovery. The transport contract owns exact classification and evidence.

[McpClient](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/client/McpClient.scala) is published only after initialize, exact 2025-06-18 result validation and notifications/initialized complete. It borrows the host transport and owns its connection; failed/interrupted initialization closes that connection immediately. listToolsPage and callTool require advertised tools capability before sending. One positive finite configured deadline (default 30 seconds) covers the complete handshake and each checked request/result projection. Timeout and caller cancellation interrupt and join owned work, preserving independent failures and cleanup defects; cleanup may exceed the deadline. Remote protocol errors become McpRemoteError with explicit Absent/Present data, while tool isError remains McpCallOutcome.Error. discoverTools takes explicit positive page/tool limits, preserves ordered duplicates and exact opaque cursors, rejects cursor cycles and excess budgets, and publishes only a complete terminal catalogue. Page metadata is omitted and discovery is not an atomic snapshot. Instructions and annotations remain untrusted data. Both reviewers approved this bounded scope and full verification passed; the [client acceptance](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/client/README.md#verification-and-acceptance) records exact identities.

[McpTool.bind](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/tool/McpTool.scala) borrows one initialized client and fixes the remote name. Host ToolDef controls the local alias/schema/read-only/concurrency declarations; annotations never supply authority. Unique object arguments pass through checked client requests. Text/image/audio map to native blocks, while resource links and embedded resources use Custom blocks; embedded payloads retain a body object containing text, blob or both. A single mcp metadata namespace preserves structuredContent, result meta/extensions and an aligned content metadata array. Extensions remain nested. Protocol tool errors retain typed payloads; RPC failures become textual Error observations through Toolkit, losing their code/data at that boundary. The [binding contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/tool/README.md) records the exact grouping. Binding itself provides no registration, resource fetching or provider multimodal serialization.

The bounded scoped manager composes this binding with owned acquisition and bounded discovery before atomic registration into immutable Toolkit snapshots. Host selection supplies ToolDef authority; collisions fail without partial publication. Pending/removing registrations retain capacity through cleanup, names expose only Ready entries, and removal joins cleanup without retargeting existing snapshots. Both independent reviewers approved the final scope and full verification passed; the [manager contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/client/README.md#scoped-manager-contract) owns exact identities, regression evidence and exclusions.

[McpToolMetadata](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/tool/McpToolMetadata.scala) supplies fixed Omit/Propagate binding policy and restricted Detached/Active correlation identity. Propagate resolves `IO[AgentError, Json.Obj]` only after the client's live Allow/Omit snapshot permits it; later changes do not revoke a resolver already started. Returned JSON is recursively validated, Active supplies the compatibility call ID, and metadata stays outside arguments/schema. Explicit client metadata is unchanged. Resolver ownership and timeout remain with the invocation host. Both reviewers approved this bounded scope; the [tool contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/tool/README.md#explicit-request-metadata) owns exact semantics and evidence.

[McpToolPresets](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/tool/McpToolPresets.scala) validates immutable defaults and original input before shallow input-wins merging. Its checked project operation removes only preset names from root properties/required after validating the original object schema; other AST fields and host flags remain unchanged. The checked binding convenience projects explicitly, while direct construction retains host schema authority. Defaults expand approved input only after authorization; they are neither constraints nor secret enforcement. McpToolBinding.withFixedArguments instead attaches a checked core policy and reuses root-schema projection with empty defaults. ToolDef.outputSchema is optional host-selected descriptive JSON. MCP selection explicitly retains, discards or overrides remote outputSchema; binding/preset copies and model-call definitions preserve that choice. No schema evaluation occurs. Host-selected Continue/Direct controls only ordinary completion after a fully successful admitted local batch; processed history, approval/Stop priorities and structured capture remain authoritative. The derived codec maps absent/JSON-null outputSchema to None and omits None; Some(Json.Null) does not round-trip. Existing construction and named copy calls can omit the default; positional patterns/Product now have eight fields, including defaulted returnMode and schemaStrictness, and dependent binaries require rebuilding. Exact acceptance is in the [core tool contract](../../modules/core/src/main/scala/com/weisgnosis/agents/core/tool/README.md#descriptive-output-schemas).

Migration: existing bind and manager register signatures retain omission. Additive `registerBindings` selects McpToolBinding(definition, metadata, presets, fixedArguments); existing construction/named copy calls can omit defaulted fields, but positional patterns/Product now have four fields and dependent binaries must be rebuilt; its concrete trait fallback fails unsupported without acquisition for custom managers until overridden. It shares the existing atomic-registration kernel and adds no owner. Custom McpConnection implementations must implement the abstract request(builder) overload, allocate/register the request ID before invoking the suspended builder, and reject ID substitution before sending. Existing request(method, params) delegates to it. AgentError adds McpRemoteError and McpErrorData; their derived tagged domain codec preserves absent versus explicit JSON null and is not the JSON-RPC wire schema.

[McpConnection](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/client/McpConnection.scala) owns scoped RPC operations over a borrowed [McpTransport](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/transport/McpTransport.scala). The host acquires the port before the connection. Active operations and pending requests are bounded; each checked send has a fresh scope. An owned worker races its action against the first terminal cause, so even a send blocked after an early reply is cancelled and joined. The reader routes replies and queues bounded ping/method-not-found responses to one control writer; incoming notifications, including directional cancellation, are ignored. Terminal publication stops admission and service activity without self-joining. One authoritative external close joins operation and service cleanup and replays cleanup defects to concurrent closers. Both reviewers approved the bounded scope recorded in the [client contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/client/README.md#verification-and-acceptance); initialization ordering and deadlines remain separate client contracts. Optional outbound cancellation uses atomic abandonment observers and the bounded connection-owned writer; full queues drop notifications and stopped admission suppresses enqueue. Initialize is excluded. HTTP eligibility begins after validated response headers, while stdio and legacy ports signal successful send; pre-header HTTP interruption is ineligible. The [cancellation contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/client/README.md#outbound-cancellation-contract) records migration for custom McpRequests implementations and transport callbacks.

[McpStdioTransport](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/transport/McpStdioTransport.scala) opens host-selected argv directly, with stderr discarded or inherited. Its single-use incoming stream uses [McpStdioFraming](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/transport/McpStdioFraming.scala): strict UTF-8 JSON-RPC separated by LF, with a positive byte limit excluding LF and including optional CR. Blank/BOM-prefixed frames and unterminated nonempty EOF are rejected. Complete frame writes and flushes share a semaphore. Invalid outbound frames and cancellation waiting for the permit leave the port usable; failure or interruption after write admission publishes terminal failure and aborts the child. One cleanup outcome covers forced direct-child termination, reaping and stream closure; consumers must stay within the transport scope. Environment and working directory are inherited without overrides. Process-tree containment, graceful shutdown deadlines, reconnects and HTTP are excluded. Independent reviewers approved this scope and full verification passed; the [transport contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/transport/README.md) records exact identities and evidence.

[McpRequests](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/client/McpRequests.scala) provides the underlying bounded correlation registry. Each register/build/send/await sequence belongs in a fresh request scope. STM removes an entry and publishes its Exit in one transaction; replies, cancellation and closure cannot settle it twice. Runtime-owned positive Long identities never wrap or reuse. Nonempty failAll causes survive intact; owner-scope closure uses a local McpError, and foreign typed request-scope failures are mapped without erasing defects or interruption. The [client contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/client/README.md) defines admission, late-reply and ownership limits.

[McpCallResult](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/protocol/McpCallResult.scala) projects ordered text, image, audio, resource-link and embedded-resource content with nested metadata and extensions. Embedded resources preserve text, blob or both. All supplied body fields must be strings, an explicitly stricter policy than accepting either valid branch of the wire union. Missing/false isError projects to Success; true projects to Error, distinct from a JSON-RPC failure. Size stays an integral compact decimal without exponent expansion; URI, base64 and timestamp strings are not interpreted.

[McpTools](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/protocol/McpTools.scala) constructs checked list/call requests and projects one discovery page. Tool order and duplicate names remain intact; schema checks cover only root object type, properties object and required string-array shape. Other schema keywords and extensions are retained without evaluation or reference resolution. Remote annotation hints are data, not permissions or concurrency guarantees. Registration remains separate; McpClient supplies explicitly bounded traversal.

[McpInitialization](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/protocol/McpInitialization.scala) adds pure request/result helpers for 2025-06-18 only. Requests advertise empty optional client capabilities. Result projection checks required implementation information and typed optional tool declarations, retains uninterpreted capability extensions, and rejects unsupported versions and malformed known fields. The initialized notification is a value; McpClient publishes it in the selected lifecycle order. Generic RPC correlation remains version-independent.

[McpMessage](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/protocol/McpMessage.scala) separates requests, notifications, successes and remote errors. Explicit checked `decode`/`fromJson` and `encode`/`toJson` conversions enforce the constant protocol marker, object payloads, unique keys and the signed 256-bit numeric identity/error-code range. Wire conversion is pure; it does not allocate request identities or correlate replies. The [package contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/protocol/README.md) defines strict-field policy and inbound/outbound error types. Manual Toolkit binding and bounded manager ownership are accepted. HTTP POST and explicit GET have separate scoped transport acceptance; caching and schema evaluation remain separate; direct SDK session replacement and real Netty same-send POST-body recovery are verified within their bounded test scopes. Previous draft API names are not compatibility obligations.

McpClientManager.make appends default-empty ToolGroups declarations and rejects existing memberships. Grouped registration checks the named group before acquisition and validates selected aliases before atomic publication. McpClientInstallation derives toolkit and memberships from one Ready-only state read; Pending, Removing and Closed entries contribute neither. Removal preserves empty declarations and retained cleanup reservations. The host passes both snapshot fields to ReAct; toolkit alone remains unfiltered and no constructed agent refreshes. Concrete trait defaults preserve custom implementations: ungrouped installation and typed unsupported grouped registration. Rebuild dependent binaries. The [grouped installation contract](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/client/README.md#grouped-installation) owns exact acceptance and migration details.

## Retained task resource API

[TaskSupervisor](../../modules/harness/src/main/scala/com/weisgnosis/agents/harness/subagent/TaskSupervisor.scala) requires both ownership methods:

```scala
def own[B](
    initialize: TaskSupervisor[A] => ZIO[Scope, AgentError, B]
): ZIO[Scope, AgentError, TaskResourceAdmission[B]]

def ownRetained[B](
    initialize: TaskSupervisor[A] => ZIO[Scope, AgentError, B]
): IO[AgentError, TaskResourceAdmission[B]]
```

Initialization is suspended and receives a nested supervisor. Accepted admission returns a [TaskResource[B]](../../modules/harness/src/main/scala/com/weisgnosis/agents/harness/subagent/TaskResource.scala) with `value: B` and `close: UIO[Unit]`; closed admission invokes no initializer. Acquired resources survive initialization and completed nested turns. For `own`, the acquiring caller Scope and parent supervisor bound that lifetime. `ownRetained` adds no caller lease after successful acquisition: the supervisor and explicit resource closure bound retention. Closing rejects nested admission, joins initialization and every running, queued or promoted nested worker, then releases retained resources.

Initialization failure, defect or interruption returns no resource and joins partial cleanup with the failing Exit. The first closure path supplies the Exit seen by resource finalizers; explicit close supplies success. Concurrent and repeated library-owned closure paths wait for the same cleanup and replay its complete outcome, including defects, with finalizers run once. This does not change repeated raw Scope.close behavior. Owned workers/finalizers must not close or await their own resource owner; masked or slow cleanup can delay closure. Hosts must stop using the exposed value after closure.

Migration: custom TaskSupervisor implementations and decorators must now implement the new abstract `ownRetained` as well as `own`. This is a source-breaking addition for custom implementations. There is no fallback; `attach` or wrapping caller-leased acquisition in a short `ZIO.scoped` cannot provide equivalent retained ownership. This process-local primitive does not serialize turns, create a child session, reopen a closed runtime or provide durable reuse. Its [paired resource tests and acceptance](../../modules/harness/src/test/scala/com/weisgnosis/agents/harness/subagent/README.md) record the bounded contract.

## Model-facing task tools

[SubagentTools.make](../../modules/harness/src/main/scala/com/weisgnosis/agents/harness/subagent/SubagentTools.scala)(registry) retains the fresh-child `agent_spawn`/`agent_task`/`agent_cancel` toolkit.

The runtime owns in-memory history, completion, cancellation and permission decisions. Immutable transformations remain pure; model calls, filesystem access, clocks and resource lifetimes are suspended in ZIO. Scoped HTTP completion, local/inline result processing and request-only context projection preserve canonical runtime authority.

The [MCP protocol boundary](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/protocol/README.md) provides independently reviewed checked JSON-RPC envelopes. It rejects ambiguous input and bounds numeric conversion; explicit 2025-06-18 initialization, discovery and tool-call payloads are also available. Bounded scoped request correlation and [borrowed-port RPC ownership](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/client/README.md) are available; both reviewers approved the connection scope and full verification passed. A [direct-process stdio adapter](../../modules/mcp/src/main/scala/com/weisgnosis/agents/mcp/transport/README.md) adds independently reviewed bounded UTF-8/LF framing and scoped process cleanup; full verification passed. The initialized 2025-06-18 client now enforces ordered initialization, tools capabilities and joined operation deadlines; both reviewers approved this bounded scope and full verification passed. Discovery pagination, Toolkit integration and HTTP remain unfinished.

Hosts explicitly install harness adapters and own their scopes. Optional local memory, transcript, result and plan stores require trusted filesystem ancestors; canonical path checks are not an atomic sandbox. Background task promotion requires a retained supervisor scope. Durable workflow replay, authenticated approval delivery, execution idempotency, remote persistence and operational monitoring belong to host integration.

Plan admission uses live policy and exact-draft review; prompt context and persisted draft text do not grant approval. Runtime-owned descendant depth and configured child factories with final static tool filtering are available. A bounded scoped registry and opt-in live parent-denial inheritance are available. Opt-in spawn/task/cancel tools, session-bound send/task/cancel tools and a host-installed inherited plan gate are available. Supervisor-owned typed resources can outlive individual turns, with nested workers joined before resource release and one shared closure outcome. This bounded primitive is approved by `path_review` and `current_docs`; exact revisions and verification are recorded in the [subagent acceptance record](../../modules/harness/src/main/scala/com/weisgnosis/agents/harness/subagent/README.md#verification-and-acceptance). Host-held child sessions are also approved by both reviewers: one runtime/history and lineage survives serialized sends with separate execution IDs and live injected authorization. The approved session adapter accepts prompt-only sends to one host-selected session and retains scoped wait/promotion/cancellation. `SubagentSessionDirectory` supplies bounded host registration and lookup of acquired sessions, with joined removal/shutdown and unchanged original lifetime bounds. `SubagentTools.forDirectory` routes send/task/cancel through registered session IDs while preserving the same bounded observations and scoped execution. `SubagentConstruction` supplies an opt-in factory path carrying static boundaries and live ancestor Deny/Plan checks into nested children while preserving their confirmation authority. Bounded MCP discovery pagination and Toolkit integration are next; declaration-driven composition, durable reuse and event routing remain unfinished; see the [immediate next work](tracker.md#immediate-next-work).

Permission gates compose with separate sequential scopes and existing vote priority. Added authorizer views retain their original policy and confirmation authority; the [permission acceptance record](../../modules/harness/src/main/scala/com/weisgnosis/agents/harness/permission/README.md#current-review-acceptance) records independent review and verification. SubagentConstruction composes these APIs when the host chooses its policy-aware construction path.

Update contracts and mappings when behavior changes. Record current reviewed scope, revision, reviewer identities and verification in affected module/package READMEs; remove resolved temporary review reports after explicit final approval. Passing local tests does not establish exhaustive upstream parity. [AGENTS.md](../../AGENTS.md) defines the engineering and acceptance requirements; Git retains historical milestones.
